# Smart Inventory & Sales Analytics System

## Requirements

* Node.js
* npm
* MySQL 8.0+
* Visual Studio Code

## Technologies Used

* React.js
* Node.js
* Express.js
* MySQL
* JavaScript

## Quick Start

Clone the repository:

```bash
git clone https://github.com/yadavshubham94250-alt/Smart-Inventory-Sales-Analytics.git
cd Smart-Inventory-Sales-Analytics/smart-inventory
```

### Backend Setup

```bash
cd backend
npm install
```

Configure your database credentials in the `.env` file using `.env.example` as a reference.

```bash
npm run db:init
npm run db:seed
npm run dev
```

### Frontend Setup

Open a second terminal:

```bash
cd smart-inventory/frontend
npm install
npm run dev
```
